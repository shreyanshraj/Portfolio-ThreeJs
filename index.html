Projects

Realtime Facial Recognition using AWS Cloud Services
A web application developed while working at ASU Film School that captures real-time video from CCTV cameras and performs facial recognition using AWS Cloud Services, including Lambda, EC2, OpenCV, S3, and SNS Notifications.
The application detects faces in the video stream and matches them against a pre-existing database of known faces stored in AWS S3.
It leverages Docker containers for scalable deployment and includes health monitoring metrics to ensure continuous, around-the-clock operation.
Traffic Data Visualization Dashboard
An interactive dashboard visualizing traffic patterns and congestion trends using Cab trips for the city of Boston and leverages Machine learning models for prediction. Users can explore vehicle flow, peak hours, and route efficiency with dynamic charts and graphs. Built with HTML, CSS, and JavaScript to provide actionable insights for urban traffic analysis.
